Engineering project case study

Rhizo PTX Integrated Control Dashboard

An integrated hardware-software dashboard combining PID control, safety interlocks and operating feedback with MOSFET and NPN transistor switching stages for system voltage and current control.

Freelance Electrical Control Engineer · Rhizo PTX / iTEK · March 2026 – September 2026

Engineering challenge

The Rhizo PTX iTEK project required a clearer and safer way to operate the complete system. The solution needed to connect newly designed electronic hardware with a software dashboard while supporting closed-loop control and explicit safety behaviour.

My contribution

Integrated dashboard

Developed a new control dashboard that brings the major system controls and operating feedback into one interface, integrating the new hardware controls and corresponding software buttons.

PID control

Integrated PID control and parameter tuning so the system can respond consistently while remaining understandable to the operator.

Safety interlocks

Added safety interlocks and layered safeguards to make control actions more deliberate and reduce unsafe operating conditions.

Electronic switching

Designed MOSFET and NPN transistor switching stages for regulation of the system voltage and current, then mapped their controls into the software interface.

Hardware-software integration

The central value of the project is the integration itself: circuit design, control behaviour and user-interface actions were developed as one system rather than as disconnected components.
